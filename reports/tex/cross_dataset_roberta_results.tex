\section*{Cross-dataset RoBERTa -- notes}

Transformer counterpart of the BiLSTM cross-dataset experiment (paper Section ``Cross-Dataset Evaluation Setup'', Tables \texttt{tab:cross\_eval\_matrix}, \texttt{\_precision}, \texttt{\_recall}, \texttt{tab:unlabelled-span-f1-cross-dataset}, \texttt{tab:loose-span-f1-cross-dataset}).

\begin{itemize}
\item Fine-tuned \textbf{RoBERTa} separately on each of the four datasets, on each dataset's \textbf{original} label set; evaluated every model on all four development sets, producing $4\times4$ span-F1 matrices (diagonal = intra-dataset, off-diagonal = cross-dataset).
\item Unified four-class space (Organization / System / Vulnerability / Malware) applied \textbf{after inference} by \textit{probability-sum late merge}: sum softmax probabilities of each coarse class's fine-grained children, then take the argmax.
\item Recipe: batch 2, learning rate $2\times10^{-5}$, 10 epochs, linear schedule, warmup 0, seed 42, maximum length 512, bf16.
\item \textbf{Union-leakage removal}: each training set drops sentences whose tokens appear in any of the four development sets, so all evaluation columns are full and leakage-free (counts in appendix).
\item Source: \texttt{models/cross\_retrained/REPORT.md} (RoBERTa), MLflow \texttt{retrained-cross-RoBERTa}.
\end{itemize}

Train datasets are on rows, development datasets on columns, and diagonal values are in \textbf{bold}.
