\section*{Multi-head RoBERTa -- results}

Fine-tuned \textbf{multi-head RoBERTa}: one shared \texttt{roberta-base} encoder with one token-classification head per dataset, each over that dataset's \textbf{original} label set (no label unification). Recipe: batch 2, learning rate $2\times10^{-5}$, 10 epochs, linear schedule, warmup 0, seed 42, maximum length 512, bf16. Cross-dataset batching reproduces the BiLSTM multi-head scheme (per-epoch dataset sampling \textbf{with replacement}, proportional to each dataset's batch count). Union-leakage removal was applied (training sentences whose tokens appear in any of the four validation sets were dropped). Scores are \textbf{span-F1 on each dataset's original-label development set}. Source: \texttt{models/multihead\_roberta/dev\_metrics.json}.

Only the \textbf{Shared: Both} (fully shared encoder) variant maps cleanly to a monolithic transformer, so the embedding-only / LSTM-only columns of the paper's BiLSTM table have no RoBERTa analog.
